# 🦅 Black Raven — Next-Gen Avian Conservation, Rescue & Sanctuary Platform

An ultra-modern, glassmorphic web application dedicated to global red-list avian species monitoring, emergency wildlife triage & diagnostic assistance, positive-reinforcement bird training, interactive parrot lifestyle matching, and sanctuary support.

---

## 🌟 Key Features

### 1. 🛡️ Endangered Species Monitoring (`#endanger-bird`)
- Track critically endangered avian specimens including **Gurney's Pitta**, **Spoon-billed Sandpiper**, **California Condor**, and **Kākāpō**.
- Integrated **Web Audio API Sound Synthesizer** generating realistic species calls directly in the browser without external audio asset dependency.

### 2. 🚑 Emergency Injured Bird Triage & AI Scanner (`#injured-bird`)
- **"picture pls" Laser Diagnostic Scanner**: Interactive drag-and-drop / file upload tool with animated laser scan line evaluating plumage and physical trauma state.
- **"what should you do..." Interactive Triage Search**: Instant keyword filtering and scenario quick-chips for Window Collisions, Fallen Baby Birds, Cat/Dog Attacks, Bleeding/Fractures, and Hypothermia protocols.

### 3. 🎓 Avian Positive Reinforcement Training (`#training`)
- Step-by-step guides covering Voluntary Step-Up, Target Stick Conditioning, and Indoor Safety Recall Cues based on positive reinforcers and fear-free handling.

### 4. 🛒 Sanctuary Care Shop & Drawer (`#shop`)
- Eco-harvested perches, hospital-grade trauma kits, acrobatic foraging wheels, and official sanctuary apparel.
- 100% responsive floating slide-out shopping cart with live price calculator and toast notifications.

### 5. 🦜 Parrot Species & Lifestyle Quiz (`#parrot`, `#bird-test`)
- Detailed species care profiles (Congo African Grey, Scarlet Macaw, Sun Conure, etc.).
- **7-Question Personality Match Quiz** (`#bird-test`): Evaluates lifestyle, space, boredom handling, and communication styles to calculate your ideal avian companion match.

### 6. 🐥 Pip the Baby Chick AI Assistant
- Floating bottom-right mascot button opening an interactive glassmorphic chat modal.
- Built-in quick query prompts and intelligent response generator for triage and care advice.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic markup, accessible labels, clean layout structure.
- **Vanilla CSS3**: Glassmorphism (`backdrop-filter`), CSS variables (dark/light themes), keyframe animations, mobile-first responsive grid.
- **Modern JavaScript (ES6+)**: SPA view router (`hashchange`), Web Audio API synthesizer, state-managed shopping cart, and quiz matching logic.

---

## 🚀 Quickstart & Local Development

No Node.js build process or bundler required. Simply serve the directory with any static HTTP web server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node / npx
npx http-server -p 8080
```

Then open `http://localhost:8080` in your browser.
